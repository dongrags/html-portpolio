### About this repository

Static site (HTML, CSS, a small amount of vanilla JavaScript) with no build step and no dependencies, published with GitHub Pages.

```
index.html            Portfolio page
assets/css/           Styles (light/dark themes)
assets/js/main.js     Theme toggle, mobile menu, scroll reveal
assets/img/           Optimized product screenshots and logos (WebP)
public/               Early HTML practice projects
```

To preview locally, open `index.html` in a browser or run `python -m http.server` in this folder.
